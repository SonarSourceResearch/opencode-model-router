opencode-model-router Plugin Installation Guide

Route prompts to the least capable model tier automatically

Prerequisites

  • OpenCode 1.18.16 or newer
  • Access to the required model APIs (Qwen, GPT via Portkey)
  • An active AWS SSO session (aws sso login) for the Qwen3.6-Sonar dogfooding model
  • PORTKEY_OPENAI_API_KEY environment variable configured
  • Authenticated access to the Repox npm registry

Step 1: Copy the Plugin Source

1 Clone or copy the plugin source to a permanent location on your machine: 
git clone https://github.com/SonarSourceResearch/opencode-model-router.git
cd opencode-model-router

Step 2: Install Dependencies

2 Verify that npm can authenticate with Repox: 
npm ping --registry=https://repox.jfrog.io/artifactory/api/npm/npm
If the command returns an authentication error, log in to Repox and retry it: 
npm login --registry=https://repox.jfrog.io/artifactory/api/npm/npm
Then install the required dependencies using Bun: 
cd opencode-model-router
bun install

Step 3: Configure OpenCode

3 Open your opencode.json configuration file and add the plugin reference and providers: 
{
  "plugin": [
    ["file:///absolute/path/to/opencode-model-router/src/index.ts", {
      "diagnostics": { "echo": true }
    }]
  ],
  "provider": {
    "model-router": {
      "npm": "@ai-sdk/openai-compatible",
      "options": { "baseURL": "http://127.0.0.1:1/v1", "apiKey": "unused" },
      "models": { "auto": { "name": "Automatic tier" } }
    },
    "sonarllm-dogfooding": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "SonarLLM Dogfooding",
      "options": {
        "baseURL": "https://sonarllm-dogfooding.aws-dev.sonarsource.com/v1"
      },
      "models": {
        "Qwen3.6-Sonar": {
          "name": "Qwen3.6-Sonar",
          "limit": { "context": 260000, "output": 8192 }
        }
      }
    },
    "portkey": {
      "npm": "@ai-sdk/openai",
      "options": {
        "baseURL": "https://api.portkey.ai/v1",
        "apiKey": "{env:PORTKEY_OPENAI_API_KEY}"
      },
      "models": {
        "gpt-5.6-sol": {
          "name": "gpt-5.6-sol",
          "reasoning": true,
          "variants": { "high": { "reasoningEffort": "high" } }
        }
      }
    }
  }
}
Replace /absolute/path/to/opencode-model-router/src/index.ts with the actual absolute path where you cloned the plugin.

Step 4: Use the Plugin

4 Restart OpenCode. In the model selector, choose model-router/auto to enable automatic tiered routing.
  • Easy prompts → routed to sonarllm-dogfooding/Qwen3.6-Sonar
  • Complex prompts → routed to portkey/gpt-5.6-sol (high variant)
  • Errors/timeouts → fallback to complex tier

How Routing Works

Diagnostics

The default configuration enables concise judge request and response summaries with "diagnostics": { "echo": true }. The selected model or fallback notification is always shown, even when detailed diagnostics are disabled.

Customizing Tiers

You can customize the judge model, trigger model, tier definitions, and fallback tier: 
"plugin": [
  ["file:///absolute/path/to/opencode-model-router/src/index.ts", {
    "judge": { "baseURL": "...", "model": "...", "timeoutMs": 5000 },
    "trigger": { "providerID": "model-router", "modelID": "auto" },
    "tiers": [
      {
        "id": "easy",
        "description": "Simple questions",
        "target": { "providerID": "sonarllm-dogfooding", "modelID": "Qwen3.6-Sonar" }
      },
      {
        "id": "complex",
        "description": "Complex reasoning",
        "target": { "providerID": "portkey", "modelID": "gpt-5.6-sol", "variant": "high" }
      }
    ],
    "fallbackTier": "complex"
  }]
]
